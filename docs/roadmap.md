# 구현 로드맵

## 0. 기반과 안전장치

- 환경 설정 검증
- 주문 제안과 리스크 결과 도메인 모델
- 건별 리스크, 포지션 상한, 레버리지, 일일 손실, 동시 보유 한도
- 단위 테스트와 CI

## 1. Bybit 데이터 (구현 완료)

- [x] V5 REST 과거 캔들 수집과 페이지네이션
- [x] WebSocket 확정 캔들, 펀딩비, 미결제약정 수집
- [x] 중복·누락·시간 순서·미확정 캔들 검증
- [x] 원본 데이터를 불변 파일로 저장

## 2. 전략 연구

- 다중 시간대 지표와 시장 국면 분류
- 추세/눌림/변동성 돌파 기준선 전략
- 수수료·슬리피지·펀딩 포함 백테스트
- 1~2년 데이터 워크포워드 및 민감도 분석

## 3. 멀티모달 분석

- 동일한 크기·축·색상·캔들 수의 차트 생성
- 수치 컨텍스트와 이미지의 구조화 분석 API
- 시점 고정 평가셋, 재현 가능한 프롬프트 버전
- LLM 미사용 기준선 대비 추가 성과 검정

## 4. Bybit 테스트넷

- 멱등적인 주문 ID, 최소 주문 단위와 가격 단위 정규화
- reduce-only 손절/목표 주문과 체결 상태 머신
- 프로세스 재시작 시 거래소 상태로 복구
- 2~4주 페이퍼/테스트넷 운영

## 5. 제한된 실거래

- 수동 승인과 킬 스위치
- 소액·1개 심볼·1배부터 시작
- 일일 손실 한도, 장애 경보, 감사 로그
- 주간 성과 검토 후에만 한도 변경
